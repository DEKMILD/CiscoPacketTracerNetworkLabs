โครงงานนี้เป็นการจำลองการกำหนดค่าและใช้งานเครือข่ายท้องถิ่นเสมือน (Virtual Local Area Network: VLAN) ผ่านโปรแกรม Cisco Packet Tracer
เครือข่ายถูกแบ่งออกเป็น 3 แผนก ได้แก่ IT HR และ Guest โดยใช้ Cisco Layer 2 Switch
แต่ละแผนกได้รับการกำหนด VLAN และ IP Subnet แยกจากกัน เพื่อสร้าง Broadcast Domain ที่เป็นอิสระ และเพิ่มการแบ่งส่วนเครือข่าย (Network Segmentation)
