กำหนดเส้นทางระหว่าง Router ด้วย Static Route และ Default Route เพื่อให้เครือข่าย LAN ต่างวงสามารถติดต่อกันได้ พร้อมเรียนรู้การตรวจสอบ Routing Table และทดสอบการเชื่อมต่อด้วย Ping และ Traceroute
